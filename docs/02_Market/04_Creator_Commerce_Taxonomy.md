# 04 — Creator Commerce Taxonomy

> 状态：Frozen v1  
> 核心问题：Creator 能够出售什么，平台需要支持哪些通用交易原语？

## 1. 分类原则

商品分类不应从“票、预约、订单”等交易界面出发，而应从购买者实际购买的价值出发。

Creator 的价值来源主要包括：

- 时间；
- 技能与专业能力；
- 现场表现；
- 内容生产能力；
- 影响力与注意力；
- 与本人建立关系的稀缺机会；
- 由个人品牌产生的实体或数字商品。

当前将 Creator Commerce 分为七类：

1. Event
2. Experience
3. Service
4. Performance
5. Content
6. Merchandise
7. Membership

这些分类用于建立统一语言和 Product Schema，不代表产品首版必须完整支持全部类型。

## 2. 总览

| 商品类型    | 用户购买什么                     | 典型交易     | 主要库存           |
| ----------- | -------------------------------- | ------------ | ------------------ |
| Event       | 参加一个公开或半公开事件的资格   | Ticket       | 时间、地点、容量   |
| Experience  | 与 Creator 发生一次特定体验      | Reservation  | Creator 时间、名额 |
| Service     | Creator 的技能与服务结果         | Booking      | 时间、能力、产能   |
| Performance | Creator 面向客户的现场出现或表演 | Hire         | 档期、地点、能力   |
| Content     | Creator 的内容生产或传播能力     | Commission   | 产能、档期、影响力 |
| Merchandise | Creator 品牌产生的实体或数字商品 | Order        | SKU、库存          |
| Membership  | 与 Creator 的持续关系和权益      | Subscription | 权益、周期、容量   |

## 3. Event｜事件型商品

### 定义

Creator 在特定时间和地点组织或参与一个事件，购买者购买参加资格。

### 购买者

- 粉丝；
- 普通观众；
- 社群成员；
- 学员；
- 活动参与者。

### 购买动机

- 观看 Creator；
- 参加共同活动；
- 学习或交流；
- 获得现场体验；
- 进入特定社群场景。

### 典型场景

- 演唱会、Live、舞台演出；
- 漫展、粉丝见面会、签售会；
- DJ Party、舞团演出；
- Workshop、公开课、分享会、沙龙。

### 交易模型

```text
Creator → Event → Ticket → Admission
```

### 关键字段

- 活动时间与地点；
- 票种和价格；
- 容量与库存；
- 购买限制；
- 入场和核销方式；
- 取消、改期与退款规则。

### 平台价值

把分散的活动信息转化为可理解、可购买、可核销的标准供给。

## 4. Experience｜体验型商品

### 定义

购买者购买的不是一般活动，而是与 Creator 本人发生一次被明确设计的稀缺互动。

### 购买者

- 粉丝；
- 高意愿支持者；
- 社群成员；
- 希望获得个性化互动的人。

### 购买动机

- 接近 Creator；
- 获得独特记忆或身份感；
- 获得个性化反馈；
- 参与普通观众无法获得的互动。

### 典型场景

- 合影、签名；
- 1v1 见面；
- 粉丝晚餐；
- 陪逛漫展；
- 私人演示；
- VIP Meet & Greet；
- 一起拍摄或限定互动。

### 交易模型

```text
Creator → Experience → Reservation → Fulfillment
```

### 关键字段

- 时长；
- 名额；
- 互动方式；
- 参与条件；
- 地点；
- Creator 确认规则；
- 安全与行为边界；
- 取消和未到场规则。

### 平台价值

帮助 Creator 将本人的稀缺时间和关系价值标准化、限量化并进行差异化定价。

## 5. Service｜技能型商品

### 定义

购买者购买 Creator 的专业能力、劳动时间或明确服务结果。

### 购买者

- 个人消费者；
- 学员；
- 专业客户；
- 小型商业客户。

### 购买动机

- 解决具体问题；
- 获得专业服务；
- 学习技能；
- 获得定制化结果。

### 典型场景

- 发型、美甲、化妆、纹身；
- 摄影、造型、设计；
- 舞蹈、声乐、乐器教学；
- 私教、咨询、指导；
- Cos 妆造、商业拍摄服务。

### 交易模型

```text
Creator → Service → Booking → Service Delivery
```

### 关键字段

- 服务时长；
- 可预约时间；
- 服务地点或线上方式；
- 基础价格和加项；
- 前置需求；
- 确认方式；
- 改期、取消和迟到规则。

### 平台价值

将 Creator 的时间和技能转化为可预约库存，并减少沟通、排期和收款摩擦。

## 6. Performance｜演出与出席型商品

### 定义

商业客户购买 Creator 在特定场景中的现场出现、表演或主持能力。

### 购买者

- 品牌；
- 商场；
- 主办方；
- 企业；
- 活动公司；
- 婚礼、酒吧、夜店和节庆活动客户。

### 购买动机

- 获得现场表演；
- 吸引客流或注意力；
- 提升活动内容和品牌效果；
- 借助 Creator 的身份和影响力。

### 典型场景

- 商场开业；
- 企业年会；
- 品牌发布会；
- 漫展和音乐节；
- 婚礼演出；
- 商务出席；
- 主持、DJ、舞蹈、演唱。

### 交易模型

```text
Business → Request / Package → Hire → Contracted Fulfillment
```

### 关键字段

- 日期与档期；
- 城市和差旅范围；
- 表演或出席内容；
- 时长；
- 起始报价；
- 技术和场地要求；
- 询价、确认和合同流程；
- 定金、尾款和取消规则。

### 平台价值

把原本依赖经纪人、MCN、私信和人工询价的供给结构化，形成未来 B2B Booking Marketplace 的基础。

## 7. Content｜内容型商品

### 定义

购买者购买 Creator 的内容制作、出镜、传播或联合创作能力。

### 购买者

- 品牌；
- 商家；
- 其他 Creator；
- 媒体与内容团队；
- 个人客户。

### 购买动机

- 获得内容资产；
- 借助 Creator 的创意和形象；
- 获得垂直受众触达；
- 完成品牌传播或联合创作。

### 典型场景

- 商业拍摄；
- 品牌出镜；
- 短视频制作；
- 产品测评；
- 摄影和模特；
- 直播；
- 视频客串；
- 品牌内容共创。

### 交易模型

```text
Buyer → Brief → Commission → Review → Delivery / Publication
```

### 关键字段

- 内容类型；
- 交付物；
- 制作周期；
- 修改次数；
- 使用权；
- 发布渠道；
- 是否包含传播；
- 报价与付款节点。

### 平台价值

将 Creator 从模糊的“合作联系”转变为拥有明确产能、档期、交付物和商业条款的 Content Inventory。

## 8. Merchandise｜商品型

### 定义

购买者购买由 Creator 品牌、作品或影响力产生的实体或数字商品。

### 购买者

- 粉丝；
- 收藏者；
- 普通消费者；
- 社群成员。

### 购买动机

- 支持 Creator；
- 获得收藏或使用价值；
- 表达身份认同；
- 获得限定内容。

### 典型场景

- 签名照、海报、摄影集；
- 服装、饰品、手办；
- 艺术作品；
- 自有品牌商品；
- 数字内容和下载产品。

### 交易模型

```text
Creator → SKU → Order → Fulfillment
```

### 关键字段

- SKU 和规格；
- 价格；
- 实物或数字库存；
- 配送或下载方式；
- 预售规则；
- 售后和退换规则。

### 平台价值

让 Creator 在同一商业身份下同时经营时间型商品和非时间型商品。

## 9. Membership｜关系型商品

### 定义

购买者持续付费，以获得与 Creator 长期关系中的身份、内容、优先权或服务权益。

### 购买者

- 核心粉丝；
- 长期学员；
- 专业社群成员；
- 高频客户。

### 购买动机

- 持续支持 Creator；
- 获得专属身份；
- 获得优先购买或预约；
- 获得限定内容和活动；
- 加入稳定社群关系。

### 典型场景

- 月度或年度会员；
- 粉丝俱乐部；
- VIP 群；
- 优先购票；
- 提前预约；
- 私享活动；
- 专属内容和折扣。

### 交易模型

```text
Creator → Membership Plan → Subscription → Recurring Entitlement
```

### 关键字段

- 计费周期；
- 权益；
- 会员容量；
- 自动续费；
- 取消和退款；
- 权益生效与失效；
- 会员等级。

### 平台价值

把单次交易升级为持续关系和可预测收入。

## 10. 类型边界

部分真实商品可能跨越多个类型。例如：

- 漫展门票是 Event，单独合影是 Experience；
- 舞蹈公开课可以是 Event，小班预约更接近 Service；
- 商业演出属于 Performance，演出宣传视频属于 Content；
- 会员中包含活动权益，但核心交易仍是持续关系。

分类应依据购买者购买的核心价值和履约模型，而不是 Creator 的职业名称。

## 11. 对产品架构的含义

七类商品表面差异很大，但底层主要由以下原语组合：

- Creator；
- Product；
- Price；
- Availability；
- Capacity；
- Location；
- Buyer；
- Order；
- Payment；
- Confirmation；
- Fulfillment；
- Cancellation；
- Entitlement。

产品设计目标不是做七套互不相干的系统，而是找出共享原语，再允许不同商品类型配置不同规则。

## 12. 待验证问题

1. 首批 Creator 最常创建的是哪三类商品？
2. Creator 是否能够正确理解并选择商品类型？
3. 哪些类型可直接下单，哪些必须先询价或人工确认？
4. 平台内交易与第三方跳转分别会如何影响转化和信任？
5. 七类商品是否需要在 Creator 端显式展示，还是由创建流程自动推断？
6. 哪些履约和售后规则必须在 MVP 首版标准化？

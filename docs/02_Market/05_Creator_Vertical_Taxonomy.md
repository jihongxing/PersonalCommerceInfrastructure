# 05 — Creator Vertical Taxonomy

> 状态：Frozen v1  
> 核心问题：哪些个人属于目标 Creator，他们凭什么能够被商业化？

## 1. 分类原则

Creator 不应按照抖音、小红书、B站或其他内容平台分类。平台只是流量来源，不是 Creator 的商业本质。

本项目按照以下问题建立 Creator Archetype：

> 这个人主要凭借什么资产产生商业价值？

同一个 Creator 可以同时属于多个原型。例如一个舞者也可能是老师、本地达人和内容 Creator。分类用于理解商品组合和启动机会，不用于给用户贴唯一标签。

## 2. Performance Creator

### 价值来源

现场表现、舞台能力和个人形象。

### 典型人群

- 歌手；
- 舞者；
- DJ；
- 乐队；
- 脱口秀演员；
- 魔术师；
- Cosplayer；
- 演员；
- 主持人、MC；
- 模特。

### 强商品类型

- Event；
- Experience；
- Performance；
- Content；
- Merchandise；
- Membership。

### 商业特点

- 时间与地点约束强；
- 公开活动能够形成粉丝交易；
- B2B 出席和演出客单价较高；
- 一个 Creator 往往可以经营多个商品类型。

## 3. Beauty & Aesthetic Creator

### 价值来源

审美判断、手艺和个性化服务能力。

### 典型人群

- 发型师、美发师；
- 美甲师；
- 化妆师；
- 纹身师、纹眉师；
- 造型师、穿搭师；
- 摄影师；
- 服装设计师。

### 强商品类型

- Service；
- Experience；
- Content；
- Event；
- Merchandise。

### 商业特点

- 时间天然是可售库存；
- 交易频率通常高于大型活动；
- 预约、改期、加项和复购是核心流程；
- 适合验证 Calendar → Availability → Booking → Payment → Relationship。

## 4. Knowledge & Skill Creator

### 价值来源

知识、教学能力、方法和专业经验。

### 典型人群

- 舞蹈、声乐、乐器老师；
- 健身教练；
- 绘画、摄影老师；
- 编程、语言老师；
- 职业教练；
- 咨询师。

### 强商品类型

- Service；
- Event；
- Experience；
- Content；
- Membership。

### 商业特点

- 预约和周期性服务明显；
- 容易形成课程、私教和会员组合；
- 线上与线下履约均可能存在；
- 信任、证明和复购通常比单次曝光更重要。

## 5. Lifestyle Creator

### 价值来源

生活方式、品味、探索能力和受众信任。

### 典型人群

- 美食博主；
- 旅行博主；
- 穿搭博主；
- 健身博主；
- 城市达人；
- 户外达人；
- 汽车达人；
- 宠物达人。

### 强商品类型

- Content；
- Event；
- Experience；
- Membership；
- Merchandise。

### 商业特点

- 内容合作是常见收入来源；
- 可以衍生路线、活动、社群和体验；
- 商品化程度取决于 Creator 是否拥有清晰垂直信任；
- 容易与本地商业和品牌需求连接。

## 6. Fan / IP Creator

### 价值来源

个人 IP、粉丝关系、角色认同和社群影响。

### 典型人群

- 娱乐博主；
- 二次元博主；
- Cosplayer；
- 游戏主播；
- VTuber；
- 社区型 Creator；
- 其他强人格或强角色 Creator。

### 强商品类型

- Experience；
- Event；
- Membership；
- Merchandise；
- Content。

### 商业特点

- 粉丝付费动机直接；
- 关系型和限定型商品潜力高；
- 漫展、直播或社群提供天然触达场景；
- 信任、安全、隐私和行为边界尤其重要。

## 7. Professional Creator

### 价值来源

专业能力、行业声誉、作品和个人品牌。

### 典型人群

- 摄影师；
- 设计师；
- 建筑师；
- 艺术家；
- 法律、医疗等知识型 Creator；
- 企业家、投资人；
- 独立顾问。

### 强商品类型

- Service；
- Content；
- Event；
- Performance / Speaking；
- Membership。

### 商业特点

- 购买者可能同时包含个人和企业；
- 客单价和非标准化程度较高；
- 案例、资质、边界声明和询价流程重要；
- 部分受监管职业需要额外合规设计。

## 8. Local Creator

### 价值来源

特定城市或区域中的供给、关系和本地影响力。

### 典型人群

- 本地美食与生活达人；
- 城市摄影师；
- 本地 Cosplayer、舞者、DJ；
- 本地活动达人；
- 本地导游型 Creator；
- 拥有线下工作室的技能服务者。

### 强商品类型

- Event；
- Experience；
- Service；
- Performance；
- Content。

### 商业特点

- Location 是核心筛选条件；
- 容易形成“某时某地有什么可购买”的需求入口；
- 本地供给密度可能形成网络效应；
- 与城市活动、场地和商家合作的潜力较高。

| Beauty & Aesthetic   | 弱至中 | 中         | 强      | 弱          | 中至强  | 中          | 中         |

## 10. 初始 MVP 候选

### 候选 A：Cosplay / 二次元 Creator

主要验证：

- Event；
- Experience；
- Merchandise；
- Membership。

代表经济模型：

> Influence → Fan Economy

优势假设：

- 粉丝互动和线下活动链路完整；
- 合影、签名、见面和周边容易被理解；
- 漫展和社群可能提供集中获客入口。

风险假设：

- 隐私、安全与未成年人问题；
- 漫展主办方和场地规则；
- 交易频率可能依赖活动周期。

### 候选 B：舞者 / 独立艺人

主要验证：

- Performance；
- Service；
- Experience；
- Event；
- Content。

代表经济模型：

> Talent → Performance Economy

优势假设：

- 单一 Creator 可以经营多个商品类型；
- 同时存在 C 端和 B 端需求；
- 能检验统一 Storefront 是否自然承载复杂供给。

风险假设：

- 商品标准化程度不同；
- 商演可能依赖询价和线下合同；
- 供给管理和履约要求较复杂。

### 候选 C：Beauty / Skill Creator

主要验证：

- Service；
- Booking；
- Calendar；
- Repeat Transaction。

代表经济模型：

> Skill → Service Economy

优势假设：

- 高频、明确的预约需求；
- 时间库存和复购价值强；
- 可以直接验证 Creator OS 的经营工作流。

风险假设：

- 已有预约 SaaS 和本地生活平台竞争；
- 部分从业者对“Creator”身份无感；
- 需求可能更偏门店经营而非个人商业身份。

## 11. 启动原则

当前不预设只做一个垂直，也不预设同时覆盖所有 Creator。

推荐决策方法是：

1. 使用统一底层抽象；
2. 选择少量商业模型差异明显的 Creator；
3. 用真实商品创建和交易测试抽象；
4. 根据 Opportunity Matrix 决定首发聚焦范围；
5. 不因首发垂直而永久固化产品架构。

## 12. Opportunity Matrix 待评估指标

后续应对候选 Creator 进行量化评估：

1. Creator 数量；
2. 线下活动频率；
3. 粉丝或客户付费意愿；
4. 可商品化程度；
5. 商品 SKU 丰富度；
6. 客单价；
7. 交易频率；
8. 时间商品化程度；
9. 交易标准化程度；
10. 平台抽佣空间；
11. Creator 痛点强度；
12. 获客难度；
13. 现有解决方案成熟度；
14. 履约与合规风险；
15. 网络效应潜力。

最终目标不是选择团队最喜欢的 Creator，而是找到：

> 最容易产生第一笔真实交易，同时最能验证 Creator OS 核心抽象的早期用户。

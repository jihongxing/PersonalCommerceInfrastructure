# 附近服务市场：中国大陆法律边界初步研究

核对日期：2026-11-11。范围：中国大陆，面向消费者的创作者服务信息、请求及可能扩展的附近发现。本文件是产品研究记录，不是某个服务品类的正式法律意见；上线前还需结合实际经营主体、合同、资金流、服务地域及具体品类复核。法条以所列官方原文为准。

## 核心判断

1. 不能把“上线附近市场”当成平台义务的唯一触发点。《电子商务法》第9条和《网络交易监督管理办法》第7条使用功能定义：通过网络为交易双方提供经营场所、交易撮合、信息发布等，供其独立开展交易活动。若现有公开 Offering、创作者入驻、顾客 Request 流程承载独立的服务交易，**即使没有站内聚合搜索和在线收款，也已有被认定为电子商务/网络交易平台的实质风险**。是否构成平台，应综合实际合同主体、页面表述、请求与成交方式判断，不宜仅看产品名称。若只是单一主体销售自有服务，角色可能是自营经营者；若仅提供通用建站/工具且不承载交易，需按实际功能另行判断。[1][2]
2. “附近”增加的主要义务是位置数据、搜索排序与线下安全管理，并不会使平台义务凭空从零开始。城市级自选区域、模糊服务范围与按距离排序、实时精确定位、地图展示具有不同的数据和测绘边界。[3][4]
3. 法律允许做服务市场，但“能力”声明不能直接等于可合法提供任何“服务”的资质。应按具体服务项目审查行政许可、人员资格、实际履约安全和消费者权益。关系消费者生命健康的服务，会进入更高的平台审核及安全保障责任区。[1]

## 产品功能与义务触发

| 功能或事实 | 法律关注点 | 设计含义 |
| --- | --- | --- |
| 第三方创作者公开发布服务，顾客发起 Request 并自行达成服务交易 | 平台身份可能已成立；《电子商务法》第9、27–34、38–40条；《网络交易监督管理办法》第7、24–26、31条 | 现在就核查平台角色、身份及资质核验、半年复核、档案及信息留存、服务协议与交易规则、评价和投诉处置；不能以“不收款”作为免责依据。 |
| 创作者入驻销售服务 | 《电子商务法》第10、12、27条；《网络交易监督管理办法》第8、24条 | 区分个人便民劳务/零星小额等登记例外与需要登记、许可的经营。例外不是免除平台身份信息核验、行业许可及税务义务。 |
| 公开跨创作者服务列表、搜索、推荐、竞价排序 | 《电子商务法》第39–40条；《网络交易监督管理办法》第14条；算法推荐规定第2、16–17、21条 | 提供真实评价入口、公开评价规则，不操纵评价；搜索展示规则需合规，竞价排名标注“广告”；若使用排序精选、检索过滤、个性化推荐等算法，要履行算法透明和用户选择等义务。 |
| 用户自选城市、行政区或粗略服务范围 | 《个人信息保护法》第6、13、17条 | 说明用途、收集最少区域信息、允许用户更改；不能仅因出现“附近”二字就断言必须取得精确定位或单独同意。 |
| 获取实时坐标、持续位置历史或行踪轨迹 | 《个人信息保护法》第23–24、28–30条 | 按实际处理内容评估是否构成敏感个人信息；对行踪轨迹等敏感信息须有特定目的、充分必要性、严格保护措施及单独同意，并告知必要性及影响。将定位数据交给独立第三方处理者还有第23条的告知与单独同意要求；委托处理适用第21条。 |
| 平台自行提供互联网地图、标注 POI、导航及路线等 | 地图与测绘合规可能成为单独议题 | 这与仅作“城市/区域文字筛选”不同。地图展示、底图来源、测绘资质、审图号和用户上传标注的责任应在具体方案明确后向自然资源主管部门及地图服务商核查；本次未核实到足以支持“附近列表一律需要测绘资质”的官方依据。 |
| 医疗、教育培训、照护、运输、旅游等特定服务；或上门、线下履约 | 《电子商务法》第12、27、29、38条及各行业专门法 | 不应采用一套通用“能力认证”放行全部服务。分品类形成许可、从业资格、禁止事项、安全预案及履约投诉的准入表；高人身风险品类先排除或单独试点。 |
| 平台规则制定、修改、封禁、申诉 | 2026-02-01施行的《网络交易平台规则监督管理办法》第3–4、7–12、19、21、23–24条 | 若属于网络交易平台，规则需显著公示、可检索；规则变更有公开征求意见和提前公示要求；负面处置要告知理由并有申诉机制，交易纠纷和个人信息责任需写清。 |

## 注意的限定

- 《电子商务法》第38条区分两类责任：平台知道或应知服务不符合人身、财产安全要求等而不采取必要措施，可与平台内经营者承担连带责任；关系消费者生命健康的商品或服务，未尽资质审核或安全保障义务造成损害，则依法承担相应责任。不能把所有服务一概说成“平台兜底”。[1]
- 《网络交易监督管理办法》第24条要求平台对入驻经营者身份等信息至少每六个月核验更新一次，第31条规定身份信息自退出平台之日起、服务和交易信息自交易完成之日起原则上均不少于三年。[2]
- 算法推荐规定第2条覆盖排序精选、检索过滤等算法技术，附近排序可能需要核查；但第24条的算法备案只针对**具有舆论属性或者社会动员能力**的算法推荐服务提供者，不是所有附近排序都要备案。[4]
- 网站/App 的 ICP、增值电信业务许可类别，以及支付结算、劳动关系、行业地方政策会随实际商业模式改变。本次没有足够事实支持“做市场必然需要 EDI 牌照”或“完全不需要许可”的结论。

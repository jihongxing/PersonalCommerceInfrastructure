> 实施计划：[114 — 按日期和时间切换公开商业主页实施计划](../09_Engineering_Governance/114_Time_Scheduled_Public_Homepages_Implementation_Plan.md)

## 1. 决策结论

保留现有的 Identity、C 号和公开地址规则：一个 Identity 只有一个终身不变的 C 号，访客始终通过
`/r/{C号}` 进入。一个 Identity 可以拥有多个商业主页版本；访客在任意给定时刻最多看到其中一个
主页。系统根据创作者设置的日期、时间和时区，在请求解析时选择当前主页。

这项变更扩展主页的数量和激活规则，不改变 C 号、公开地址、资料披露边界、已发布服务条件、预约
规则或 C 号不是认证凭据的信任边界。

## 2. 对象和公开解析

公开解析固定为：

```text
C 号 → Identity → 当前时间匹配的主页版本 → 该主页选定的公开资料 → 已发布服务
```

- `Identity` 与 C 号仍是一对一；C 号不可变、不可转让、不可复用。
- `Homepage Version` 是同一 Identity 下的一份可独立管理的公开资料和服务投影配置。
- `Activation Window` 是主页版本可被自动选中的日期和时间区间。
- `Active Homepage` 是解析请求发生时被选中的唯一主页，是运行时结果，不是另一个持久化身份对象。
- `/r/{C号}`、复制链接和二维码保持不变；切换主页版本不生成新地址。

每个时间点必须满足：

```text
0 或 1 个 Active Homepage
```

如果当前时间没有匹配的时间窗口，系统使用该 Identity 的一个已发布默认主页；没有可用默认主页时，
公开入口返回主页不可访问。这样保留现有单主页行为，同时允许时间窗口覆盖默认主页。

## 3. 状态和时间窗口

主页版本继续使用现有公开状态：`UNPUBLISHED`、`PUBLISHED`、`PAUSED`。只有 `PUBLISHED` 的版本
可以作为默认主页或时间窗口目标；`ACTIVE` 仅表示当前解析结果，不作为创作者可手工设置的状态。

第一期时间窗口使用明确的起止日期和时间：`[startsAt, endsAt)`，结束时刻不包含在窗口内，且
`startsAt < endsAt`。保存时创作者选择 IANA 时区，服务端把时间转换为 UTC 保存，同时保留时区名称
供工作台显示和后续编辑。第一期不引入按周重复、复杂日历规则或跨主页优先级；需要这些规则时另行登记
产品变更。

同一 Identity 的已启用时间窗口不得重叠。冲突在 API 保存时返回明确的冲突错误，数据库事务和约束也必须
阻止并发写入形成重叠。时间窗口的目标主页必须属于同一 Identity；目标被暂停或取消发布后，该窗口不再
参与选择，系统回退到可用默认主页。

主页可以在没有已发布服务时发布，访客看到“尚无服务”。服务发布、下架或最后一个服务下架不改变主页
版本状态或时间窗口；服务列表仍按现有已发布和可请求条件过滤。

## 4. 创作者和访客行为

创作者可以：

- 创建、编辑、预览、发布、暂停和归档多个主页版本；
- 为主页版本设置、修改和删除未来时间窗口；
- 指定一个已发布版本作为默认主页；
- 在工作台看到当前激活主页、下一次切换时间、默认主页和窗口冲突提示；
- 预览某个主页版本或指定时间点的解析结果。

访客无需登录，访问同一个 C 号地址即可获得当前时间对应的主页。访客不能通过参数选择未激活版本，
不能绕过发布状态或读取创作者的草稿、暂停版本、未选资料和私有字段。

预览使用认证管理接口，并可以指定测试时间；公开接口只使用服务端当前时钟，不接受访客提供的时间参数。
时间由 API 服务器统一解释为 UTC，不能依赖浏览器本地时间决定公开内容。

## 5. 兼容和规范事件

- 现有 `/api/v1/public/homepages/{reference}` 合同和 `/r/{C号}` 地址保持不变；响应结构继续返回当前主页
  的公开资料和已发布服务。
- 现有 `/api/v1/private/homepage` 保留为兼容的当前主页投影；新管理接口返回版本、默认主页、时间窗口和
  当前激活结果。
- `storefront_viewed` 仍只记录成功打开当前已发布主页的事实；预览、时间窗口冲突、不可访问和故障不记录。
- 主页版本、默认设置、窗口创建、修改、删除、发布和暂停需要可审计记录，但不新增 Canonical Event。
- `creator_published` 仍只由首次符合条件的已发布服务触发；时间切换不触发该事件。

## 6. 安全和边界

所有版本和时间窗口操作必须由服务端校验当前账号对 Identity 的 OWNER 权限。C 号、主页地址和二维码是
公开引用，不是认证凭据。公开投影使用现有字段白名单和 `no-store` 缓存策略，日志和 trace 不记录邮箱、
令牌、请求体或完整私有资料。

此决策不引入搜索、推荐、社交账号验证、支付、结算、Marketplace、CRM、自动预约或复杂 Calendar 能力。

本决策登记产品行为变化；数据库迁移、API、工作台、公开解析和本地自动化验收已经完成。生产环境、真实
公网访问和外部平台验证不在本地验收范围内，实施证据由 DEV-064 执行台账维护。

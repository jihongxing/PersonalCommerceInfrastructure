## 1. 决策范围

当前 `apps/web-v2` 的工作台同时承载账号状态、身份资料引导、能力和服务入口、预约审核，以及完整的对外主页管理。主页管理还包含公开资料选择、主页方案、发布状态、默认主页、自动切换窗口、预览、分享链接和二维码，导致工作台难以作为日常运营入口使用。

本决策批准将对外主页的完整管理界面迁移到个人资料区域，并重新组织界面层级。它只改变 Creator 端的导航、信息架构、展示密度和交互呈现，不改变任何业务规则。

`DEV-065` 用于登记本次界面层变更的追溯事实。它不是新的领域偏差，也不构成 VS-01 产品规则增补；本次没有 PRD 语义修订。

## 2. 决策结论

### 2.1 工作台定位为日常运营首页

工作台只呈现需要快速查看或处理的内容：

- 登录账号和 C 号；
- 商业资料完成度；
- 能力和服务的下一步入口；
- 预约审核入口及其待处理摘要；
- 对外主页的轻量状态摘要。

工作台不再展开主页方案列表、时间窗口表单、资料选择器、二维码生成器或主页预览内容。对外主页摘要只提供当前状态、当前公开资料或简短空态、稳定地址，以及进入设置和打开主页的入口。

### 2.2 个人资料区域增加内部 Tab

顶部 Creator 导航继续保留“个人资料”。个人资料页面内部增加两个 Tab：

1. `资料`：查看和编辑商业身份资料；
2. `对外主页`：管理公开方案、发布状态、自动切换和分享工具。

默认 Tab 为 `资料`。对外主页 Tab 必须支持可直接访问的深链接，例如 `/profile?tab=public`；刷新、返回和登录后跳转不能丢失当前 Tab。现有 `/profile/edit` 继续只负责资料编辑，不与主页发布操作混合。

### 2.3 对外主页按渐进披露组织

对外主页页面按以下顺序展示：

1. **当前公开状态**：状态、当前公开资料、稳定 `/r/{C号}` 地址、下一次切换时间和主要操作；
2. **公开方案**：同一 Identity 下的主页方案列表及方案级状态；选中方案后才显示方案操作；
3. **自动切换**：选中方案的时间窗口列表和窗口编辑入口；新增或编辑时间窗口使用独立的表单区域或弹层；
4. **分享工具**：复制链接、打开主页、二维码和预览，不与时间窗口表单混排。

“主页版本”在界面中优先称为“公开方案”，但 API、数据库和代码领域类型继续使用既有 `Homepage Version` 术语，避免 UI 文案改变工程合同。

## 3. 不变量和兼容边界

以下规则保持不变：

- 一个 Identity 只有一个终身不变的 C 号；
- `/r/{C号}`、复制链接和二维码地址保持不变；
- 一个 Identity 可以有多个主页方案，但同一时间最多有一个 Active Homepage；
- 只有 `PUBLISHED` 方案可以公开、作为默认方案或作为时间窗口目标；
- 主页可以在没有已发布服务时发布，并显示“尚无服务”；最后一个服务下架不改变主页状态；
- 注册成功不自动公开资料，发布仍由创作者主动执行；
- 公开解析、服务过滤、预览权限和 C 号不是认证凭据的信任边界不变；
- `UNPUBLISHED`、`PUBLISHED`、`PAUSED`、`ARCHIVED` 及 Active Homepage 的既有语义不变；
- 主页发布、暂停、恢复、资料选择和时间窗口维护不新增 Canonical Event；既有技术审计规则不变；
- 数据库迁移、后端路由、OpenAPI 合同和公开响应字段不因本次 UI 重构改变。

界面不能把“接口加载失败”显示成“尚未设置”。主页管理、资料加载和摘要加载分别保留加载中、成功空态、失败重试和认证失效状态。

## 4. 状态呈现规则

主页页面顶部展示一个聚合状态，方案列表展示实际方案状态。聚合状态只由既有管理查询结果推导，不写入新的状态字段：

| 界面状态   | 展示条件和含义                                           |
| ---------- | -------------------------------------------------------- |
| 尚未设置   | 没有主页方案；不是接口失败                               |
| 未发布     | 有方案，但当前没有可对外展示的已发布主页                 |
| 已发布     | 当前解析结果有公开主页                                   |
| 按时段切换 | 存在有效时间窗口，并显示当前公开方案和下一次切换时间     |
| 已暂停     | 当前没有可对外展示的主页，且方案均处于暂停或不可公开状态 |

如果状态推导所需数据不完整，显示加载失败和重试，不猜测为“尚未设置”。方案级状态仍直接显示 `草稿`、`已发布`、`已暂停` 或 `已归档`，避免把聚合状态误认为持久化状态。

## 5. 交互原则

- 首屏先回答“现在对外展示什么”，再提供配置入口；
- 发布、暂停、归档和切换公开资料前显示明确的目标资料和稳定链接；
- 自动切换只在需要时展开，窗口编辑显示时区、开始时间、结束时间和启用状态；
- 预览使用既有认证预览接口，不能把预览当成公开发布；
- 复制和二维码使用同一个规范公开地址，不生成新的地址；
- 桌面和移动端都保持状态、主要操作和错误信息可见，不依赖悬停或隐藏按钮；
- 重要操作提供键盘可达的控件、明确的焦点状态和可读的错误反馈。

## 6. 明确不做

本次不新增或修改：

- Homepage、Identity、Commerce Profile、Offering、Activation Window 等领域对象；
- 任何数据库表、索引、迁移或后端服务；
- 认证、权限、C 号分配、公开解析和服务发布规则；
- 规范事件、事件名称、审计语义或公开字段白名单；
- 周期性日历、访客选择主页、社交账号验证、支付、Marketplace、CRM 或预约规则。

## 7. 设计验收边界

实施完成后必须能够证明：

1. 工作台不再渲染完整对外主页管理器，只显示摘要和跳转入口；
2. 个人资料页面可以在“资料”和“对外主页”之间切换，并支持深链接和刷新；
3. 对外主页页面仍可完成既有主页方案、发布、暂停、默认方案、预览、分享和时间窗口操作；
4. 新用户、无方案、无服务、已发布、已暂停、按时段切换和接口失败状态均有正确展示；
5. C 号、`/r/{C号}` 地址、公开内容边界和服务过滤结果与重构前一致；
6. API、数据库和规范事件测试不因本次 UI 结构变化产生行为差异。

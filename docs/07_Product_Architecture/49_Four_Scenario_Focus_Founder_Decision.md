> **登记日期**：2026-11-20

## 1. 当前战略范围

`PCI STRATEGY — FOUR-SCENARIO FOCUS`

`ACTIVE SCENARIOS: SERVICE / MEMBERSHIP / PROGRAM / GOODS`

`DEFERRED SCENARIOS: PROJECT / RIGHT`

暂停新场景扩张，仅维护已进入主线的 Service、Membership、Program、Goods，并依据已证实的业务问题实施必要改进。四个领域保留独立的供给、交易与履约语义及现行 Founder Decisions。[个人商业主页](47_Personal_Commercial_Homepage_Founder_Decision.md)仍是已发布且符合公开条件的供给的主要发现入口。

## 2. 搁置与恢复

- **Project**：停止研究、业务验证、Founder Decision 准备和实施。保留 PCI-PD-010 的历史研究、分支、工作树、提交与证据。
- **Right**：停止业务验证、首期规则裁决、产品设计和实施。保留已进入主线的 [PCI-PD-011 历史研究](../08_Execution/PCI-PD-011-Right-Sixth-Commercial-Scenario-Decision-Package.md)及证据；该研究的待裁决项没有获批。

本决定覆盖此前对 Project 与 Right 的推进安排。任何恢复工作均须重新取得 Founder 明确授权。

## 3. 不变的边界

本决定是产品战略范围与推进安排，不改写 [Conceptual Baseline 41](41_Global_Commercial_System_Conceptual_Baseline.md)、F01–F04、D01–D12、[Decision 42](42_Commercial_Scenario_Sequencing_Founder_Decision.md) 的场景进入原则或任何既有场景业务合同，不建立统一生命周期。`ACTIVE SCENARIOS` 表示维护范围，不表示已授权对外开放。Goods 继续默认关闭，`REAL_MONEY_ENABLED=false`，不授权生产部署、外部 Pilot 或真实资金操作。
